# 当前开发计划

按用户授权顺序实施：冻结公开 JSONL/SDK 契约 → 同一事实投影的任务状态与双语 → 终端降级及人工矩阵 → 只读项目适配层与贡献文档 → 同包分发验收准备与自身历史对照。逐项实际完成状态见 [实施状态](core-experience/STATUS.md)，不能以脚本总通过替代人工终端、原生交付或真实收益。

真实模型测试已按用户要求暂停。保留 deepseek-flash、不限 Token/费用总额的可复现配置和完整计量，待用户恢复测试后才执行；本轮不再发起付费预检。五类场景各三个独立任务，每任务每版本五次，共 150 次计划运行，固定历史 commit 与候选、成对随机顺序且一次仅运行一对。失败、取消、跳过和未知计量全部保留，未达到门槛不作产品优势宣传。

版本、标签和已发布资产保持现状。正式 npm/Release 安装交付仍受准确候选、Linux 构建、两平台同包消费者、安全与专用 Windows native 门禁约束。发布身份或机器缺失保持阻塞，不降低门槛，不将源码候选当成已交付安装包。

默认模型修复策略和团队开关保持现状；Node 单包完整支持，Python/Rust/Go 保留基础检查发现，不静默安装新工具链。IDE、ACP、Web/Desktop、远程入口及完整新增语言支持另行决策。
