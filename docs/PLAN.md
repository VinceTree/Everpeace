# 当前计划

当前工作为安全边界与隐私加固，问题 01–12 的设计、实现和限制见 [安全加固](architecture/SECURITY_HARDENING.md)。交付顺序为文件竞争/路径 → 敏感读取/外传 → 验证/MCP → 隐私/综合验收。

Windows 本地 NTFS 是本轮安全文件后端的支持范围；其他平台明确不可用，不以 Node 回退或模拟测试冒充原生通过。跨平台原生后端、可写映射/内核攻击模型、MCP 原子 executable 加载与完整依赖完整性仍需后续工作。真实模型测试按用户要求暂停，不能把离线攻击回归当作模型免疫证明。

用户已授权更新源码候选号、提交和推送。提交使用 `[skip publish]`，保持测试启用，不创建 tag 或 Release。正式安装包仍遵守原有准确候选、跨平台消费者、安全与专用 Windows native 门禁，不降低发布标准。最新检查证据和未覆盖项目见 [HANDOFF](HANDOFF.md)。

此前公开契约与核心体验的未验收终端、安装和真实收益事项保留在 [实施状态](core-experience/STATUS.md)，不自动扩大为本轮任务。
