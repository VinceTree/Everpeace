# Security policy

Please report suspected vulnerabilities privately using [Report a vulnerability](https://github.com/VinceTree/Everpeace/security/advisories/new). Do not open a public issue containing exploit details, credentials or personal data.

The latest published stable release receives security fixes. Reports against main are welcome, but main does not carry a stability guarantee. Users of older releases should upgrade first.

Include the exact version or commit, operating system, permission and sandbox configuration, enabled MCP/Skill integrations, a minimal reproduction and the expected impact. Use disposable workspaces and test credentials. Do not attack other users or third-party services.

We aim to acknowledge reports within seven business days on a best-effort basis. We reproduce and assess impact, agree on a fix, validate the affected boundaries, and coordinate disclosure with the reporter. There is no guaranteed fix date. Credit is offered with the reporter's consent; sensitive details stay private until coordinated disclosure.

High/Critical dependency findings block required checks and publishing. Maintainers review lower-severity findings, investigate scanner failures, update affected dependencies or record a version-bound exception with rationale and review evidence. A missing scan is not a clean scan.

## 中文

请通过上面的 GitHub 私密漏洞报告入口提交问题，不要在公开 Issue 中发布利用细节、凭据或个人数据。安全修复支持最新正式版；main 接受报告但不承诺稳定，旧版用户请先升级。

请提供准确版本或 commit、平台、权限与沙箱配置、MCP/Skill 配置、最小复现和影响范围。使用隔离工作区及测试凭据，不攻击其他用户或第三方服务。

我们尽力在七个工作日内确认收到，随后复现、分级、修复、验证并协调披露；不承诺固定修复日期。经报告者同意后致谢，协调披露前保密。严重依赖漏洞阻止合并与发布；低级别结果和扫描故障也必须处理，缺少报告不能视为通过。
